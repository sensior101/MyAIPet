# 기술 정책

## 로컬 / 클라우드 처리 기준
**원칙: 이번 프로젝트는 100% 로컬 처리. 클라우드 처리는 하지 않는다.**

| 처리 | 로컬 | 클라우드 | 기준 |
|---|---|---|---|
| VAD / STT | ✅ | ❌ | 음성은 가장 민감한 데이터, 지연에도 불리 |
| 의도 분류 / 이미지 품질·임베딩 | ✅ | ❌ | 빠르고 가벼움 |
| LLM | ✅ | ❌ | 유료 API 미사용 원칙 |
| VLM | ✅ | ❌ | 사진은 외부로 보내지 않음 |
| TTS | ✅ | ❌ | 오프라인 시연 |
| 기억 저장 | ✅ | ❌ | 휴대폰 로컬 DB |
| 웹 검색 | — | (범위 밖) | 도입 시: 사용자가 켠 경우에만, 검색어만 전송, 결과는 로컬 LLM이 요약 |

향후 클라우드를 검토할 조건: 로컬 모델로 품질 목표(NFR-06~09)를 끝내 달성하지 못하고, 사용자가 명시적으로 동의한 경우에 한해 해당 기능만.

## 컨텍스트 저장 범위
| 데이터 | 저장 여부 | 보관 기간 | 저장 위치 | 삭제 방법 |
|---|---|---|---|---|
| 현재 대화 맥락 (프롬프트용) | 메모리에만 | 최근 10턴 또는 1,500토큰 | RAM | 앱 종료 시 삭제 |
| 대화 원문 기록 | 저장 | 30일 | Room `conversation` | 자동 만료, 설정에서 전체 삭제 |
| 음성 원본 | **저장 안 함** | — | — | — |
| 사진 원본 | **저장 안 함** | 분석 후 즉시 폐기 | RAM | — |
| 시각 기억 썸네일 | 저장 | 기억 삭제 시까지 | 앱 내부 저장소 | 기억 화면 |
| 이미지 특징 벡터 | 저장 | 기억 삭제 시까지 | Room `visual_memory` | 기억 화면 |
| 장기 기억 | 저장 | 사용자가 지울 때까지 | Room `memory` | 기억 화면, 음성 삭제 |
| 펫 상태 | 저장 | 영구 | Room `pet_state` | 설정에서 초기화 |
| 성능·오류 로그 | 저장 | 7일 | 앱 내부 파일 | 자동 만료 (대화 내용은 기록하지 않음) |

프롬프트에 넣는 범위: 성격 프롬프트 + 펫 상태 요약 + 관련 기억 최대 5개 + 시각 설명(있을 때) + 최근 대화. 전체 컨텍스트 4,096토큰 이내.

## 목표 응답시간
(NFR-01~05와 같은 값. 실측 후 함께 조정)

| 구간 | 목표 | 최대 허용 | 측정 방법 |
|---|---|---|---|
| 발화 종료 감지 (VAD) | 0.6초 | 1.0초 | 마지막 음성 프레임 → SPEECH_END |
| 발화 종료 → STT 결과 | 0.8초 | 1.5초 | 로그 |
| 의도 분류 | 0.05초 | 0.1초 | 로그 |
| 기억 검색 | 0.1초 | 0.3초 | 로그 |
| 프롬프트 → LLM 첫 토큰 | 1.0초 | 3.0초 | 로그 |
| LLM 첫 문장 완성 → TTS 첫 음성 | 0.5초 | 1.0초 | 로그 |
| **일반 대화: 발화 종료 → 첫 음성** | **3.0초** | **5.0초** | 20회 중앙값 |
| 촬영 + 품질 검사 | 0.5초 | 3.0초 | 로그 |
| 이미지 임베딩 + 매칭 | 0.3초 | 0.6초 | 로그 |
| VLM 설명 | 3.0초 | 8.0초 | 로그 |
| **시각 요청: 발화 종료 → 첫 음성** | **6.0초** | **10.0초** | 20회 중앙값 |

시간을 줄이는 방법: LLM 상주 로딩, 문장 단위 TTS 스트리밍, 촬영과 STT 이후 처리를 병렬로, VLM 설명과 임베딩 병렬 실행, 기억 처리는 답변 후 백그라운드.

## Timeout 기본값
| 구간 | Timeout | 초과 시 동작 |
|---|---|---|
| LISTENING 무발화 | 5초 | IDLE |
| STT | 1.5초 | 재요청 (POL-03) |
| 촬영 | 3초 | 안내 후 IDLE |
| VLM | 8초 | 1회 재시도 → "잘 모르겠어" |
| LLM 첫 토큰 | 3초 | fallback 문구 |
| LLM 첫 문장 | 6초 | fallback 문구 |
| LLM 전체 | 15초 | 생성 중단, 말한 데까지 |
| TTS 문장당 | 2초 | 효과음 + 화면 텍스트 |
| THINKING 상태 전체 | 10초 | fallback 문구 → IDLE |
| LOOKING 상태 전체 | 10초 | "잘 안 보였어" → IDLE |
| CONFIRMING 응답 | 8초 | 취소 처리 → IDLE |
| 기억 처리 (백그라운드) | 30초 | 건너뜀 + 로그 |
| 기기 제어 (BLE) | 1초 | 무시 |

## 시각 매칭 기준값
| 값 | 초기값 | 결정 방법 |
|---|---|---|
| T_high (같은 물건 확정) | 0.85 | 시연 물건 3종 × 각도 5개로 같은 물건 유사도 분포 측정 → 하위 10% 지점 |
| T_low (새 물건) | 0.70 | 비슷한 다른 물건 유사도 분포 → 상위 5% 지점 |

## 모델 운영
| 모델 | 로딩 시점 | 해제 시점 | 양자화 |
|---|---|---|---|
| LLM | 앱 시작 (상주) | 앱 종료 | Q4_K_M |
| VLM | 첫 시각 요청 (미리 로딩 옵션) | 5분 미사용 또는 메모리 부족 | Q4 |
| STT / VAD / TTS | 앱 시작 | 앱 종료 | 모델 제공 형식 |
