## 상세

### FR-01 로컬 LLM 텍스트 대화 — Must
- **설명:** 휴대폰에서 로컬 LLM(Qwen3-1.7B 기준)으로 텍스트 대화를 한다. 최근 대화 맥락을 유지한다.
- **인수 조건:**
  - [ ] 비행기 모드에서 텍스트를 입력하면 답변이 나온다.
  - [ ] 3턴 전에 말한 내용을 언급하는 질문에 맞게 답한다.
  - [ ] 답변이 토큰 단위로 화면에 이어서 표시된다.

### FR-02 버튼으로 음성 입력 시작 + 발화 끝 감지 — Must
- **설명:** 대화 버튼(앱 화면, 이후 인형 버튼)을 누르면 듣기 시작하고, VAD로 말이 끝난 것을 자동 감지한다.
- **인수 조건:**
  - [ ] 버튼을 누르면 1초 안에 LISTENING 상태가 된다.
  - [ ] 말이 끝나고 1초 이내에 발화 종료를 감지한다.
  - [ ] 5초 동안 말이 없으면 IDLE로 돌아간다.

### FR-03 음성 인식 — Must
- **설명:** 한국어 발화를 로컬 STT로 텍스트로 바꾸고 신뢰도를 함께 낸다.
- **인수 조건:**
  - [ ] 조용한 실내에서 대표 시나리오 문장 10개 중 9개 이상을 의미가 바뀌지 않게 인식한다.
  - [ ] 빈 결과나 낮은 신뢰도는 LLM으로 넘기지 않고 재요청한다. (SC-11)

### FR-04 음성 출력 — Must
- **설명:** 답변을 문장 단위로 합성하여 첫 문장이 완성되면 바로 재생한다.
- **인수 조건:**
  - [ ] 첫 문장 생성 후 TTS 첫 음성까지 목표 시간 이내 ([tech-policies.md](tech-policies.md))
  - [ ] 여러 문장 답변이 끊김 없이 이어서 재생된다.

### FR-05 일관된 펫 성격과 말투 — Must
- **설명:** 성격 프롬프트에 따라 친근한 반말, 짧은 답변을 유지하고, 모르는 것은 지어내지 않는다.
- **인수 조건:**
  - [ ] 대표 시나리오 답변 전부가 반말이고 2문장 이내다.
  - [ ] 저장된 기억에 없는 사실을 물으면 모른다고 답한다. (10회 중 9회 이상)

### FR-06 의도 분류 — Must
- **설명:** 사용자 발화를 `CHAT` / `VISION` / `MEMORY_QUERY` / `MEMORY_DELETE` / `MEMORY_UPDATE` / `SCHEDULE`로 분류한다.
- **인수 조건:**
  - [ ] 시연 문장 20개("얘 봐봐", "이거 뭐야", "몽이 기억나?", "몽이 기억 지워" 등)를 18개 이상 맞게 분류한다.
  - [ ] "몽이 기억나?"(MEMORY_QUERY)에서는 카메라를 켜지 않는다.

### FR-07 촬영 + 사진 품질 검사 — Must
- **설명:** 시각 요청일 때만 촬영하고, 밝기와 흔들림을 검사해 기준 미달이면 1회 재촬영한다.
- **인수 조건:**
  - [ ] 카메라 설정이 OFF면 촬영을 시도하지 않고 안내한다.
  - [ ] 어두운 방에서 "너무 어두워서 잘 안 보여" 안내가 나온다.
  - [ ] 촬영 중에는 화면(이후 LED)에 카메라 사용 표시가 보인다.

### FR-08 이미지 설명 — Must
- **설명:** 로컬 VLM으로 사진 속 물건과 장면을 설명한다.
- **인수 조건:**
  - [ ] 시연 물건 10종 중 8종 이상의 종류를 맞게 말한다. (예: 곰 인형, 컵)
  - [ ] 신뢰도가 낮으면 추측임을 밝힌다. (SC-13)

### FR-09 시각 기억 저장 — Must
- **설명:** 사용자가 소개한 물건의 특징 벡터, 썸네일, 설명을 저장하고 장기 기억과 연결한다.
- **인수 조건:**
  - [ ] SC-01 후 기억 화면에 썸네일과 "몽이" 기억이 1건 보인다.
  - [ ] 같은 물건을 두 번 소개해도 시각 기억이 중복 생성되지 않는다.

### FR-10 같은 물건 다시 알아보기 — Must
- **설명:** 새 사진의 특징 벡터를 시각 기억과 비교해 같음 / 애매함 / 새 물건으로 판단한다.
- **인수 조건:**
  - [ ] 앱 재시작 후 같은 물건을 각도·조명을 바꿔 5번 보여주면 4번 이상 이름으로 알아본다.
  - [ ] 비슷한 다른 물건 5번 중 이름을 잘못 말하는 경우가 0번이다. (애매함 → 확인 질문은 허용)

### FR-11 장기 기억 자동 추출·저장 — Must
- **설명:** 턴이 끝나면 백그라운드에서 기억 후보를 추출하고, 중요도·신뢰도를 판단해 저장한다.
- **인수 조건:**
  - [ ] "얘 이름은 몽이야"가 기억으로 저장된다.
  - [ ] 인사말 같은 의미 없는 대화는 저장되지 않는다.
  - [ ] 기억 처리 때문에 다음 답변이 늦어지지 않는다.

### FR-12 기억을 반영한 답변 — Must
- **설명:** 관련 기억을 검색해(최대 5개) 프롬프트에 넣고 답변에 자연스럽게 반영한다.
- **인수 조건:**
  - [ ] SC-02, SC-03에서 이름과 "어릴 때부터"를 모두 언급한다.
  - [ ] 기억에 없는 내용을 기억이라고 말하지 않는다.

### FR-13 기억 조회·삭제 화면 — Must
- **설명:** 앱에서 저장된 기억과 시각 기억을 목록으로 보고, 개별 삭제·전체 초기화를 할 수 있다.
- **인수 조건:**
  - [ ] 저장 직후 목록에 바로 나타난다.
  - [ ] 개별 삭제와 전체 초기화가 동작하고, 전체 초기화는 확인 대화상자를 거친다.

### FR-14 음성으로 기억 삭제 — Must
- **설명:** "○○ 기억 지워"라고 하면 대상을 찾아 확인 질문 후 삭제한다.
- **인수 조건:**
  - [ ] "응"이면 삭제, "아니"나 무응답이면 삭제하지 않는다.
  - [ ] 삭제 후 같은 물건을 보여주면 처음 보는 물건으로 반응한다.
  - [ ] 대상이 여러 개거나 없으면 재질문한다. (SC-25)

### FR-15 재질문·확인 질문 — Must
- **설명:** 지칭 대상이 불명확하거나, 유사도가 애매하거나, 되돌리기 어려운 명령일 때 묻는다. ([policies.md](policies.md) POL-01, POL-02)
- **인수 조건:**
  - [ ] SC-21, SC-22, SC-25가 문서대로 동작한다.
  - [ ] 같은 내용으로 재질문은 최대 1번이다.

### FR-16 오류 안내와 fallback — Must
- **설명:** 인식 실패, 촬영 불가, timeout, 메모리 부족 시 정해진 안내를 하고 앱이 멈추지 않는다. ([policies.md](policies.md) POL-03, POL-04)
- **인수 조건:**
  - [ ] SC-11~SC-15가 문서대로 동작한다.
  - [ ] 어떤 오류에서도 앱이 종료되지 않고 IDLE로 돌아온다.

### FR-17 인터넷 없이 전체 동작 — Must
- **인수 조건:**
  - [ ] 비행기 모드에서 SC-00 전체가 성공한다.
  - [ ] 앱이 인터넷 권한 없이 빌드되어도 Must 기능이 모두 동작한다.

### FR-18 끼어들기 — Should
- **인수 조건:**
  - [ ] 펫이 말하는 중 버튼을 누르거나 말하면 0.5초 안에 멈추고 듣기 시작한다.
  - [ ] 펫 자신의 목소리로는 끼어들기가 발생하지 않는다.

### FR-19 기억 충돌 시 확인 후 수정 — Should
- **인수 조건:**
  - [ ] SC-24: "사실 콩이야" → 확인 질문 → "응"이면 이후 콩이로 부른다.

### FR-20 펫 상태 — Should
- **설명:** 친밀도·기분·에너지를 대화에 따라 갱신하고 말투에 반영한다.
- **인수 조건:**
  - [ ] 펫 상태 화면에서 값이 대화 후 바뀌는 것이 보인다.
  - [ ] 앱을 재시작해도 값이 유지된다.

### FR-21 대화 상태 표시 — Should
- **인수 조건:**
  - [ ] 듣는 중 / 생각 중 / 보는 중 / 말하는 중이 화면에 구분되어 표시된다.

### FR-22 블루투스 헤드셋 입출력 — Should
- **인수 조건:**
  - [ ] 헤드셋 마이크로 듣고 헤드셋 스피커로 답한다.
  - [ ] 연결이 끊기면 휴대폰 마이크·스피커로 자동 전환된다.

### FR-23 일정 기억 + 능동 대화 — Could
- **인수 조건:**
  - [ ] SC-05: 다음 날 설정 시간대에 먼저 말을 건다. 조용한 시간과 OFF 설정을 지킨다.

### FR-24 호출어 — Could
- **인수 조건:**
  - [ ] 정해진 호출어로 LISTENING이 되고, 10분 동안 TV 소리에 잘못 반응하는 횟수가 1번 이하다.

### FR-25 인형 하드웨어 모듈 연결 — Could
- **인수 조건:**
  - [ ] 인형 모듈의 버튼·마이크·스피커·카메라로 SC-00이 성공한다.

### FR-26 터치 센서 반응 — Could
- **인수 조건:**
  - [ ] 머리를 쓰다듬으면 짧게 반응하고 친밀도가 오른다.
