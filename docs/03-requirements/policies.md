# 기획·운영 정책

## POL-01 사용자 확인이 필요한 명령
되돌릴 수 없거나 기존 정보를 바꾸는 명령은 실행 전에 한 번 확인한다.

| 명령 유형 | 확인 방식 | 확인 없이 실행 가능한 경우 |
|---|---|---|
| 기억 삭제 (개별) | 음성: "몽이에 대한 기억을 지울까?" → 응/아니 | 앱 화면에서 직접 삭제 버튼을 누른 경우 |
| 기억 전체 초기화 | 앱 화면 확인 대화상자만 허용 (음성으로는 불가) | 없음 |
| 기억 수정 (기존 정보와 충돌) | "몽이가 아니라 콩이로 바꿔서 기억할까?" | 앱 화면에서 직접 수정한 경우 |
| 카메라·마이크 설정 변경 | 앱 화면에서만 가능 | — |
| 새 기억 저장 | 확인하지 않음 | 항상 (기억 화면에서 언제든 삭제 가능) |
| 능동 대화 끄기 | 확인하지 않음 | 항상 (끄는 쪽은 안전) |

- 확인 응답: 긍정("응", "그래", "맞아", "지워") / 부정("아니", "아니야", "취소", "하지 마")
- 8초 안에 답이 없거나 알아듣지 못하면 **취소로 처리**하고 "그럼 그대로 둘게."라고 말한다.

## POL-02 불명확한 요청의 재질문
- **판단 기준:**
  - 지칭어("이거", "그거", "아까 그거")의 대상이 0개 또는 2개 이상 (SC-21, SC-25)
  - 시각 유사도가 T_low 이상 T_high 미만 (SC-22)
  - 의도 분류 신뢰도가 낮고, 실행하면 상태가 바뀌는 의도(삭제·수정)인 경우
- **재질문 방식:** 선택지를 구체적으로 제시한다. ("컵이랑 인형이 보이는데, 어느 거?")
- **횟수 제한:** 같은 요청에 대해 최대 1번. 그래도 불명확하면
  - 조회성 요청 → 가능한 범위에서 답한다. (보이는 것을 모두 설명)
  - 변경성 요청(삭제·수정) → 실행하지 않고 "기억 화면에서 직접 고를 수 있어."라고 안내한다.
- **하지 않는 것:** 사용자가 답을 피한 질문(예: 이름)은 같은 대화에서 다시 묻지 않는다. (SC-23)

## POL-03 실행 실패 시 안내
원칙: 짧게, 펫 말투로, 사용자가 할 수 있는 행동을 함께 알려준다. 기술 용어는 쓰지 않는다.

| 실패 유형 | 오류 코드 | 사용자 안내 | 후속 동작 |
|---|---|---|---|
| 음성 인식 실패 (1회) | `EMPTY_INPUT`, `LOW_CONFIDENCE` | "잘 못 들었어. 한 번만 다시 말해줄래?" | LISTENING |
| 음성 인식 실패 (연속 2회) | 〃 | "주변이 좀 시끄러운 것 같아. 나중에 다시 불러줘." | IDLE |
| 카메라 설정 OFF | `PERMISSION_DENIED` | "지금 카메라가 꺼져 있어. 설정에서 켜줄래?" | IDLE |
| 사진이 어두움 | `LOW_QUALITY` | "너무 어두워서 잘 안 보여. 밝은 데서 보여줄래?" | IDLE |
| 사진이 흔들림 | `LOW_QUALITY` | "흔들려서 잘 안 보였어. 잠깐 멈춰줄래?" | LISTENING |
| 물건을 모름 | `LOW_CONFIDENCE` | "음… 잘 모르겠어. 이거 뭐야?" | LISTENING |
| 응답 시간 초과 | `TIMEOUT` | "잠깐 머리가 멈췄어. 다시 말해줄래?" | IDLE |
| 메모리 부족 | `OUT_OF_MEMORY` | "잠깐만, 정신 좀 차릴게." | 모델 재로딩 후 IDLE |
| 인형 연결 끊김 | `DEVICE_DISCONNECTED` | (휴대폰 스피커로) "인형이랑 연결이 끊겼어. 폰으로 계속할게." | 휴대폰 장치로 전환 |
| 대상 기억 없음 | `NOT_FOUND` | "그건 기억에 없는 것 같아." | IDLE |
| 그 외 | `INTERNAL` | "앗, 뭔가 꼬였어. 다시 해볼래?" | IDLE + 로그 |

## POL-04 Fallback
| 실패 지점 | 1차 fallback | 2차 fallback |
|---|---|---|
| STT | 재요청 1회 | IDLE, 앱 화면에 텍스트 입력 안내 |
| 사진 품질 | 자동 재촬영 1회 | 안내 후 종료 |
| VLM | 1회 재시도 (VLM 재로딩 포함) | "잘 모르겠어" + 사용자에게 물어봄 |
| 시각 기억 매칭 | 애매하면 확인 질문 | 새 물건으로 처리 |
| LLM 첫 문장 timeout | 생성 취소 → 고정 안내 문구 | — |
| LLM 생성 중 중단 | 이미 말한 문장까지만 출력 | — |
| TTS | 미리 녹음된 효과음 + 화면 텍스트 | 화면 텍스트만 |
| 인형 장치 | 휴대폰 마이크·카메라·스피커로 전환 | 텍스트 채팅 |
| 기억 처리(백그라운드) | 1회 재시도 | 로그만 남기고 건너뜀 (사용자에게 알리지 않음) |

## POL-05 능동 대화
- 기본값: **OFF**. 사용자가 켜야 동작한다.
- 허용 시간대: 기본 09:00~22:00 (설정 가능). 조용한 시간에는 말하지 않는다.
- 하루 최대 5회, 연속 능동 대화 사이 최소 1시간.
- 사용자가 대화 중이면 끼어들지 않는다. (IDLE일 때만)
- 일정 알림("오늘 시험이지?")과 일반 말걸기를 구분하여 각각 끌 수 있다.
- 사용자가 "그만 말 걸어"라고 하면 바로 OFF로 바꾸고 알린다.

## POL-06 개인정보 (녹음·촬영·기억)
- **녹음:** 버튼·호출어 이후에만 STT로 넘긴다. 원본 음성은 저장하지 않는다.
- **촬영:** 시각 요청이 있을 때만 촬영한다. 원본 사진은 저장하지 않고, 시각 기억으로 저장되는 물건만 썸네일을 남긴다.
- **표시:** 마이크·카메라 사용 중에는 화면(이후 인형 LED)에 항상 표시한다.
- **기억:** 모든 기억은 앱 내부 저장소에만 저장하고, 사용자가 조회·수정·삭제·전체 초기화할 수 있다.
- **민감 정보:** 건강, 비밀번호, 금융 정보, 다른 사람의 개인정보로 보이는 내용은 자동 저장하지 않는다. 사용자가 "기억해"라고 명시한 경우에만 저장하고 `sensitive` 표시를 한다.
- **타인:** 외출 중 다른 사람의 대화나 얼굴은 기억으로 저장하지 않는다.
- **외부 전송:** 기본 동작에서 외부 전송은 없다. (온라인 기능은 이번 범위 밖)
